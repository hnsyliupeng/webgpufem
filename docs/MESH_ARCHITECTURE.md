# 多级 TPMS 共形网格：底层架构与实施边界

## 1. 目标和现状

目标是从 App 的真实一至三级隐式材料场，生成**完整有限盒**中带材料标签、材料界面共节点、满足既有几何/拓扑/质量门槛的三维 C3D4 网格，再经过独立检查后导出或求解。自动自适应必须同时尊重局部壁厚、界面交线、曲率、单元质量与资源约束。截面、体素、原始场可视化和周期商网格不是该交付物。

目前不存在可通过这些条件的二级/三级网格生成路径。`native/cgal-periodic.cpp` 在 CGAL 周期三角剖分中构造材料域，返回统计和一个 Z=50% 截面，**不返回完整三维单胞或有限盒**。多材料共面句柄检查只适用于周期商网格；最差质量、材料边界多面边和原始场错分均仍存在。`native/cgal-implicit.cpp` 尝试有限盒，但真实默认模型曾达到顶点上限。`cut-tet.js`、MMG 和 SimWild 离散输入路径会受采样、界面或质量限制。详见 README 的真实二、三级对照，不能把这些原型或本文件当作合格求解器。

## 2. 必须分开的对象和契约

1. **几何源 `GeometryModel`**：保存 App 参数、物理尺度和版本指纹，提供连续材料场、分类、可选导数及严格的周期资格。材料 0 表示空隙；1–3 是不同材料。对于多材料，必须表达真实边界及交线，不能只以节点标签或单个标量并集代替。
2. **界面复合体 `InterfaceComplex`**：输出独立的材料对界面、三相/多相交线、交点及外盒特征，所有参与域引用同一顶点和边。多相交线允许三张或更多界面汇合；对整个界面联合体强行要求普通二流形是不正确的。需保留实体来源、曲面误差与交线容差，处理周期偏移和盒面交点。
3. **网格 `Mesh3D`**：全局节点表（物理坐标）、正向四面体节点索引、材料标签、边界/界面实体及来源关系。任何两个相邻材料的公共三角面必须引用**同一组节点 ID**；相同坐标但不同节点 ID 不是共节点。修改必须是完整事务，不能把部分候选写回可用结果。
4. **验证 `MeshAudit`**：对实际 `Mesh3D` 而非截图重新计算几何、拓扑、材料分区和质量。统计采样只用于发现问题，不能证明最薄壁或全域 Hausdorff 误差。已有的边邻接、体积、周期面、采样混淆矩阵均是必要但不充分条件。
5. **工件状态**：`diagnostic`（可能不完整）→ `candidate`（完整网格但未验证）→ `verified`（所有硬约束满足）；失败、超限、取消或结构改变必须丢弃候选。只有 `verified` 可以进入导出/求解；实验算法或采样通过不得自动提升状态。分析结果还需材料、载荷、边界条件和收敛验证。

前端显示、服务流和后端都应携带模型版本/任务 ID、状态、明确失败原因和单元/节点统计；取消进程不能留下半个网格或复用旧图。UI 的质量截面应同时展示全体质量统计；截面是诊断而非三维网格。

## 3. 生成管线与自适应

```text
App 参数和版本 -> 周期资格 / 尺度与资源预估
  -> 材料边界及多相交线发现、保护 -> 共同节点的界面复合体
  -> 空间尺寸场（薄壁、曲率、界面间距与外盒）
  -> 受约束共形体网格 -> 局部腔体重构与质量控制
  -> 有限盒裁剪/拼接或直接受保护盒面生成
  -> 独立几何、拓扑、质量及容量检查 -> verified / 拒绝
```

自动尺寸必须依据**有证据的局部最小特征尺度**并限制相邻尺寸增长率；有限差分 `|f|/|∇f|` 是局部估计，不是最薄壁的下界。输入边界或对偶线段多次穿越时必须能表达全部相关界面，而不是只取端点不同或返回第一个交点。交线和盒边需要保护，避免某一材料的近邻独立移动。

传统 Delaunay 半径/最短边约束不能消除所有薄片；反复缩小尺寸或直接把 Jacobian 当插点条件，均不能保证终止或质量。应设计带界面与材料约束的局部腔体重构：拒绝倒置和自交；严格保持界面及交线身份；对重构前后材料体积、几何距离、质量分布和拓扑进行事务检查。必要时拒绝不可满足的输入，并给出局部位置与原因。后处理不能将未达标网格伪装成合格结果。

## 4. 周期到有限盒：共节点必须在构造时成立

周期商网格以“顶点句柄 + 整数周期偏移”标识一个具体顶点实例；各单胞复制后，同一物理顶点必须归并为同一个全局节点，不能按浮点坐标容差盲目焊接。每个跨盒面的四面体须按六个盒平面裁剪，相邻材料共享的边与面必须共用同一交点、同一多边形三角化，且对角线与访问顺序、面法向无关。周期边和盒边相交处也需要统一节点身份。截面色块对齐不证明这些条件。

本轮加入隔离实验 `native/conforming-box-clip.hpp` 和 `native/experimental-periodic-box.hpp`：共享原始顶点 ID 与平面/边交点缓存，使用按节点 ID 选择的事务内确定性耳切三角化（尚不保证改变输入顺序后的节点编号或对角线不变），再以凸多面体内部点构建四面体；真实周期实例按顶点句柄及绝对整数偏移建立节点。`npm run test:conforming-box-clip` 覆盖两个共享材料界面的四面体、2×2×2 多材料合成格子经六平面裁剪、材料体积、节点共享、非流形面、完全盒内单元、仅接触盒面和退化拒绝。

这只是**不可导出**的架构试验，不是完整有限盒实现：浮点判定、极小面、精确几何和盒面保护尚未解决；中心扇形四面体化可能制造新的薄片；未实现跨多个物理单胞的完整拼接或真实模型全局拓扑/几何验证。真实二级模型在裁剪时遇到几乎重合的交点（两点坐标差约 1e-15 个周期单位），原型拒绝 `cannot robustly triangulate clipped polygon`；真实三级拒绝 `degenerate clipped face`。真实 GUI 两级错误处理测试见 `screenshots/cgal-box-clip-{1,2}.png`（`npm run test:cgal-box-clip-gui`，服务需配置此隔离版本）。不允许靠放大焊接容差或跳过退化面来隐藏缺陷。需结合精确谓词、稳定的拓扑身份与受保护的盒面局部重构；精确谓词本身也无法保证质量。

编译 `TPMS_BOX_CLIP_PROBE` 可复核这一隔离路径，顶点上限 100000，不接入默认构建、导出或求解。结果即使未来得到完整单胞盒，也必须通过原始场、界面、薄壁与质量检查才能成为候选。

## 5. 验收门槛与测试矩阵

- **输入与尺度**：真实 App 二、三级默认及边界变体；不同层材料；明确单位、周期数和用户尺寸；超内存/超时/取消安全失败。
- **几何**：完整域及各材料分量、孔道、最薄壁；界面及交线到原始场的双向误差；逐层体积、对照采样和多分辨率收敛。采样错分/体积误差本身不是严格界。
- **拓扑与共节点**：每个四面体正向，面最多两个体单元；材料公共面两侧节点 ID 完全相同；各材料边界的边和顶点邻域、交线、外盒边角及周期拼接一致；检测非流形、悬挂节点、裂缝、重复面和自交。多材料合法交线须有专门测试。
- **质量**：不降低现有严格要求：所有四面体角点最小 Jacobian > 0.3、最大长高比 < 10，无退化/倒置；同时报告按材料、界面距离的质量分布，防止仅改善最差值而恶化大面积单元。裁剪后重新计算。
- **端到端**：解析多材料交线及薄壁、极近盒面的顶点、跨周期面、不同复制序列、退化与资源上限；真实 App 二级和三级全流程、GUI 真实三维/截面和截图、结果文件重读验证；网格收敛后才可进入力学基准。

单元测试或解析模型通过不能代替真实多级结构；本轮真实模型裁剪失败，所以尚未完成第 4、5 阶段，不开放导出或求解。

## 6. 代码定位

- `native/app-field.hpp`、`tests/gui-app-field-parity.cjs`：原始材料场及与 App 对照。
- `native/cgal-periodic.cpp`：周期域生成、优化事务、统计和截面，不返回完整有限盒。
- `native/periodic-edge-audit.hpp`、`native/shared-periodic-face.hpp`：周期边界与共享面必要检查。
- `native/quality-gate.hpp`、`native/tet-quality-score.hpp`：候选质量与既有阈值。
- `native/conforming-box-clip.hpp`、`native/experimental-periodic-box.hpp`：本轮有限盒共节点裁剪原型。
- `index.html`、`serve.cjs`：GUI、取消和原生任务流；尚无 `verified` 多材料完整盒交付。
- `docs/REFERENCES.md`：TPMeSh 与其他上游项目的实际能力和许可。TPMeSh 的周期单域方法可作参考，但不能直接推断其解决本项目的多材料交线与完整盒问题。
