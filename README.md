# TPMS 层级结构实验台

基于用户提供的 `TPMS-standalone-v18.txt`，入口为 `index.html`。无需构建：在本目录运行 `python3 -m http.server 8000`，用支持 WebGL 2 的浏览器访问 `http://localhost:8000/`。也可将整个目录部署为静态网站。请同时保留 `voxel-stl.js`、`cut-tet.js`、`mmg-worker.js`、`mmg-level-worker.js`、`quality-opt.js`、`quality-opt-worker.js`、`quality-surface.js`、`quality-surface-worker.js` 和 `vendor/mmg`。

## 现有功能及边界

- 原文件提供一至三级 TPMS 几何预览、剖面、参数检查、八叉树界面细分预览及简单质量指标。八叉树有悬挂节点，不是求解网格；2:1 平衡只是细分粗单元，不是通用网格修复。
- 原文件的求解网格是均匀体素 C3D8 网格；界面为阶梯近似。可视化、面连通/材料重叠检查和 INP 导出不代表曲面贴体或网格收敛。
- 原文件提供线弹性静力有限元求解，不是显式动力学、接触、冲击、屈曲、塑性或 FE²。结果仅供探索，需独立基准、网格收敛、单位和材料验证后才能用于工程。
- 新增二进制 STL：先在「有限元网格」生成网格，再点击「导出体素 STL」。导出的是当前实体体素外表面，单位按 mm 构造，STL 格式本身不记录单位；不是光滑 TPMS 曲面，可能存在非流形边或不连通部分，不能保证可打印。材料界面不导出为独立面。改变结构或分辨率后必须重新生成网格。
- **STEP 导出未实现**：不能把 STL 改名为 STEP；需要 CAD 内核生成并验证真实几何。自适应求解网格、自动几何修复、显式准静态/动态冲击和 FE² 均未实现。参考项目没有集成。

## 实验性 TPMS 切割四面体

「TPMS 边界切割四面体网格」对一级结构的隐式函数做节点采样、线性插值切割背景四面体，并显示所得体单元的边界三角形；不是体素六面体。显示四面体数量、归一化平均比质量与直方计数。`screenshots/05-cut-tetrahedra.png` 是 GUI 实测截图。

这是研究原型：仅一级单材料、均匀背景；曲面为分片线性近似，采样可能漏掉薄壁或改变拓扑。未实现自适应、修复、多材料界面、曲面误差、完整流形/连通性验证，也没有接入力学求解器；不得用于工程求解。单元平面切割的体积、正方向与简单边界裂缝测试不等于 TPMS 几何验证。

四面体网格现可按 Z 剖切展示真实单元截面，提供面连通分量、边界非流形边、角点归一化 Jacobian、最大长高比、最小面角和体积检查。C3D4 INP 导出仅在单一面连通分量、无非流形面/边、最小角点 Jacobian > 0.3、最大长高比 < 10 时启用；满足这些阈值仍不代表几何误差或分析结果已验证。默认结构 28³ 测试虽连通，但最小 Jacobian 约 0.0018、最大长高比约 114，**严重不合格，导出被禁用**；12³ 更会出现大量断连。必须先实现网格优化及几何验证。

### MMG 重网格（实验）

生成单连通、无非流形边/面的一级结构切割网格后，可设置离散边界容差并点击「MMG 四面体重网格」。该操作在浏览器 Worker 内调用本地 MMG3D WASM；完成后重新计算体单元质量、连通性及体积变化。MMG 失败、拓扑变化或体积变化超过 2% 时丢弃结果。截图 `screenshots/06-mmg-remesh.png` 为实际 GUI 操作记录。

MMG 的容差针对**输入离散曲面**，不是对原 TPMS 隐式曲面的误差保证；局部几何可能变化，体积检查不能代替 Hausdorff 误差、壁厚或网格收敛验证。当前不支持材料界面、误差驱动自适应、求解中重网格或场变量映射。测试案例 20³ 重网格后角点 Jacobian 约 0.0243、最大长高比约 27.58，仍不达标且不能导出；分辨率 20³ 与 28³ 原网格体积差异也表明采样尚未收敛。请勿用于工程求解。直接使用 `file://` 可能因浏览器 Worker/WASM 同源限制失败；通过静态 HTTP 服务打开。

内核 [MMG-WASM 0.1.0](https://github.com/loumalouomega/MMG-WASM) 基于 MMG 5.8.0，许可证为 LGPL-3.0-or-later，许可证与上游说明随 `vendor/mmg` 提供；用户应遵守相应分发条款。

### MMG 隐式域直接生成（实验）

「MMG 隐式曲面生成四面体」将 TPMS 隐式函数采样到协调的背景四面体，交给 MMG3D 的 level-set 离散化，提取负域四面体并检查；不是体素六面体。支持取消长时间运行。半盒解析几何的负域体积和连通性测试通过，但默认 TPMS 的 12³ GUI 实测仍有 144 个面连通分量、最差角点 Jacobian 0.0171、最大长高比 31.65，**不合格，导出被禁用**；20³ 实测超过 180 秒未完成，不能声称有效。请勿用于求解。`npm run test:level-gui` 可重现 12³ 浏览器测试。

### 几何采样筛查

点击「检查几何采样误差」可计算较细中点采样体积、与四面体体积的相对差，以及抽样边界点的隐式函数残差／梯度一阶距离估计。C3D4 导出还要求筛查体积相对差 ≤5%、距离估计 P95 ≤0.5 mm（至少 100 个有效采样点）；该筛查只是必要条件，不是严格误差界，低梯度处距离估计可能失真。默认 12³ 实测体积相对差约 67%，明确不合格；该问题还没有修复。

### 双界面薄壁四面体（实验）

新增「双界面薄壁四面体生成」：对一级、无外壳 TPMS 的有符号场分别切割正负两侧，使薄壁即使没有背景节点落在壁内也可被捕获。解析薄板测试包含节点均在壁外的情况，验证体积与面连通。当前采用分片线性近似、均匀背景，尚不支持多级材料或自适应。

默认结构 28³、MMG 容差 1 mm 的 GUI 实测：112137 个四面体，面连通分量 1，最差角点 Jacobian 0.1101、最大长高比 7.92；几何采样体积相对差 3.29%、边界距离估计 P95 0.203 mm。**Jacobian 未达到 0.3，仍不合格，导出禁用；采样筛查通过不等于几何精度或求解可靠性已验证。** GUI 前后截图分别为 `09-two-sided-tet-28.png` 和 `13-shell28-mmg-check.png`，可通过 `npm run test:shell-gui` 复现。

四面体面板默认显示完整三维边界（可拖动旋转、复位），「三维剖切体单元」在外表面基础上显示剖面与真实四面体相交形成的多边形；「二维 Z 剖面」仅显示当前高度截面。旧单场实验会漏掉薄壁，不应作为完整网格；一级无外壳结构可尝试双界面生成。`screenshots/13-shell28-mmg-check.png` 与 `screenshots/14-tet-cutaway.png` 分别记录完整边界及剖切视图。这些图不改变网格质量尚未达标、不可求解的结论。

### 质量评价与迭代

四面体面板提供平均比质量直方图，以及最差角点 Jacobian 单元的截面定位。MMG 修正可设置 1–4 次迭代和停止目标，可取消；每次记录单元数、最小 Jacobian、最大长高比和相对于输入网格的体积变化。只保留拓扑与体积检查通过、Jacobian 相比输入提高且长高比不恶化的候选中最好的结果。停止目标不是导出阈值：导出仍要求 Jacobian >0.3、长高比 <10 和几何采样筛查通过。

默认一级案例的两次 GUI 迭代实测最小 Jacobian 均约 0.1101，**没有达到 0.3**。`screenshots/15-quality-worst.png` 显示直方图、迭代记录和最差单元位置。可执行 `npm run test:shell-gui` 重现。

二、三级案例分别记录了模型和八叉树预览（`screenshots/level2-*`、`screenshots/level3-*`）；八叉树不是协调有限元网格。相应 `*-tet-unsupported.png` 记录四面体入口的实际拒绝状态：多材料协调界面与二、三级四面体网格**尚未实现**，这些截图不构成二、三级有限元网格验证。`npm run test:levels-gui` 可重现这一检查。

### 内部节点局部质量优化

「局部修正最差单元」按每轮最差 Jacobian 单元筛选邻域，在固定全部边界节点的前提下搜索内部节点位置，最大化该节点相邻四面体的最小角点 Jacobian；可设置轮数、每轮候选单元数并取消。每次候选都拒绝反向或退化单元；结束后重新检查连通性、边界拓扑、全局最差 Jacobian、最大长高比及体积，检查失败或最差 Jacobian 未改善时保留原网格。该方法不改变边界拓扑，无法修复需要移动表面的劣质单元。修正后必须重新做几何采样筛查。

默认一级 28³ 案例中，MMG 后最差 Jacobian 约 0.1101；以每轮 300 个候选、每次 8 轮执行两次局部修正后约为 0.2270，最大长高比约 5.74，体积不变。该结果仍未达到 0.3，**不能导出作为合格求解网格**，并且曲面误差筛查不是收敛验证。截图见 `screenshots/18-local-optimization-verified.png`，可使用 `npm run test:local-gui` 复现。二、三级多材料协调网格仍未实现。

### 实验性边界切向修正

「受限边界切向修正」针对最差单元邻域，仅允许平滑边界的节点沿近似切平面小幅移动；外盒与尖锐区域固定，并对每个节点限制相对于首次边界修正前的位置的累计位移（最大 0.2 mm）。候选检查受影响四面体方向及相邻边界三角面退化/法向变化；结束时检查拓扑、质量与体积。后续内部修正保留位移基准，禁止在边界试验后继续 MMG 重网格以免丢失基准。

默认一级案例的 GUI 实测中，上限 0.05 mm 时最差 Jacobian 从 0.2270 提高到 0.2307；依然低于 0.3。该试验**没有完整的自交或严格曲面距离验证**，即使几何采样筛查通过也禁止导出。截图 `screenshots/19-surface-experiment.png`，可用 `npm run test:surface-gui` 重现；仅一级、无外壳结构支持当前流程，二、三级多材料协调网格仍未实现。

### 深度联合优化（实验性）
网格页面提供固定边界的内部 2↔3 拓扑翻转及“深度联合优化”：后者在独立 Worker 内交替进行内部节点 patch 搜索和内部腔体翻转，最多六轮；每个阶段均复检边界三角面集合、面连通性、非流形、总体积、最差 Jacobian 和最大长高比，并保留阶段记录。局部翻转允许全局最差值暂时持平，以便后续阶段处理并列最差单元；若整个事务没有改善全局最差值，则丢弃结果。翻转和固定边界平滑不能保证达到质量阈值，也不是无自交或几何收敛证明。边界实验污染标记始终保留，不能因此解锁导出。一级 28³ 的一次实际 GUI 测试中，MMG 后最差 Jacobian 0.1101，四轮联合优化达到 0.2048（长高比 5.90），仍未达到 0.3 的导出阈值。

### 二级/三级隐式切割实验
“二级/三级隐式切割四面体（实验）”按当前多级 `geo` 函数的实体并集对背景四面体做线性边界切割，不是体素单元。它仅是合并实体的几何试验：不构造材料界面或单元材料编号，采样可能漏掉薄壁，绝不可用于真实求解或导出。网格可作质量、几何采样和联合优化试验；实验网格即使连通分量大于一也可尝试 MMG 和联合优化，但必须保持分量数，不能由此判断实体连通正确。每种处理都保留实验标志、禁止 INP 导出。

默认二级预设在 20³ 网格实测 305728 四面体、17 个分量，采样体积相对差 12.46%，边界距离估计 P95 4.305 mm，深度联合优化未改善全局最差值；MMG 返回失败。三级默认预设实测 318656 四面体、1 个分量，采样体积差 1.69%，P95 2.379 mm；联合优化最差 Jacobian 0.0008 → 0.0012，仍严重不合格。距离是局部一阶估算而非严格界，也不能代替逐层几何/材料界面验证。GUI 可复现：`npm run test:hier-gui`（需设置 `CHROMIUM_PATH`）。

质量优化候选选择使用固定容量最大堆，只保存 K 个最差单元，将每轮全量排序 O(N log N)、O(N) 临时索引替换成 O(N log K)、O(K)；这提高候选筛选效率，但不会消除几何漏采、材料界面及低质量瓶颈。

### 通用 CAD 实体贴体网格（Gmsh）
执行 `npm install` 然后 `npm run serve`，在服务地址打开应用。服务设置 COOP/COEP，供 Gmsh WebAssembly 使用；直接打开文件或普通静态服务不能使用该功能。界面可导入含实体的 STEP / IGES / BREP，或创建带球形空腔的 OpenCASCADE 示例并导出真实 STEP。通过 Gmsh 的曲率尺寸控制、最小/最大网格尺寸、三维 Delaunay 与优化生成 C3D4；支持 1–4 线程，显示真实四面体剖面、边界、质量和耗时。优化前后均检查网格质量和拓扑，若退化则保留优化前结果。GUI 自动测试：`npm run test:gmsh-gui`（需 `CHROMIUM_PATH`）。

`@loumalouomega/gmsh-wasm` 使用 GPL-2.0-or-later；分发或修改时须遵守其 GPL 条款及上游源代码提供要求。此路径依赖输入文件已有可网格化的 CAD 实体，并不自动将 TPMS 隐式曲面转换为精确 CAD，不能解决二级/三级 TPMS 材料界面、薄壁漏采与质量失败。仅对单 CAD 体提供严格筛查后的 C3D4 几何网格导出：需连通、无非流形、Jacobian > 0.3、长高比 < 10、相对 CAD 体积差 ≤ 2%、不少于 100 个三角面重心到 CAD 曲面采样且 P95 ≤ 0.5 mm；这些采样不是严格几何误差界。导出不含材料、截面、载荷、边界条件或分析步骤，不能将筛查等同完整求解验证。多体模型没有材料接口导出。

二级和三级预设的实际 GUI 四面体剖面与剖切图：`screenshots/level2-tet-slice-20.png`、`screenshots/level2-tet-cutaway-20.png`、`screenshots/level3-tet-slice-20.png`、`screenshots/level3-tet-cutaway-20.png`；这些截图展示的是不合格的实验网格，不表示通过验证。28³ 加密实测：二级 772224 单元、5 个分量、体积采样差 5.24%、边界 P95 3.574 mm；三级 804288 单元、1 个分量、体积采样差 3.60%、P95 1.761 mm；两者联合优化均未改善最差 Jacobian。加密并未解决漏采和单元质量问题。

### 多材料分区与薄壁复审（实验，不合格）
新增“共享多材料界面四面体（实验）”：对背景四面体中的线性化材料场建立分区，给每个体单元材料标签，按共享节点提取材料界面；二级/三级宏观双域无外壳预设将宏观板壳拆成 `a-s` 和 `-a-s` 两个界面，避免两端都在薄壁外侧时漏掉穿过背景单元的壳体。解析薄板及三材料平面测试验证体积、面连通、共享界面和材料标签，但这并不能证明复杂 TPMS 几何正确。材料界面节点和外边界固定的内部节点优化检查各材料体积、拓扑和质量，所有材料试验网格仍禁止导出；拓扑翻转和边界移动未实现材料标签保护，禁止用于此网格；可使用下述锁定材料界面的 MMG 迭代。

GUI 实测的宏观双域预设（参考中点采样，仅诊断，不是严格几何真值）：12³ 时，二级从直接三场切割的 127 个连通分量降到 7，三级从 145 降到 1；但非流形边分别仍为 4 和 360。20³ 时二级体积相对采样差 6.93%、21 个分量、272 条非流形边，三级差 37.92%、19 个分量、2332 条非流形边，质量极差。三级次级/三级 `abs` 场仍会在节点同侧时漏采；分别线性化各材料场再做布尔运算与对真实非线性场做布尔运算并不等价。20³ 迭代没有得到可接受的质量改进。这个方法在真实 TPMS 上尚不正确或高效，不能作为完成的有限元网格划分，须继续解决多层薄壁特征解析分割、共享界面交线的退化处理和自适应贴体网格收敛。

### Gmsh 离散 TPMS 曲面重网格（单材料试验）
新增“Gmsh 曲面贴体重划分”：从已生成的单连通闭合单材料四面体恢复有向边界三角面，由 Gmsh 分类离散曲面、重参数化、体四面体化并调用 Netgen 优化；检查连通性、非流形、体积变化≤2%、最差 Jacobian 改善且最大长高比不恶化。该路径需要 `npm install` 和 `npm run serve` 的跨源隔离环境，限制输入边界不超过 80000 面；多级、多材料及非流形输入不允许，以防材料界面丢失。实验标识在后续优化中保留且永久禁止此网格导出，不把离散三角面的近似当作精确 CAD。

### App 二级/三级 TPMS 的 MMG 多材料迭代
对 App 当前的“共享多材料界面四面体”直接使用 MMG3D：写入每个四面体的材料编号，将外边界三角面和材料交界三角面标记为 required（固定），并对不满足长高比约束的候选执行固定界面的内部节点修正。每次迭代后核对外边界几何三角面集合、带材料对的界面几何面集合、每种材料体积、连通分量及非流形数，并要求最差 Jacobian 改善而最大长高比不恶化；没有通过则保留原网格。结果保留实验标志，不得导出或用于真实求解。固定界面确保不丢失已有离散界面，但不能修复输入中的漏采、断连、非流形边或不准确的几何界面。

### SimWild 多材料接口路线（可选后端，实验且未达标）

不再基于现有粗网格平滑：GUI 将**当前 App 的 `geo()` 多材料场**在独立 Worker 内采样，通过 marching cubes 构造各材料的闭合三角曲面，再交给 [WildMeshing Toolkit 2.0 SimWild](https://github.com/wildmeshing/wildmeshing-toolkit) 将曲面插入同一个四面体背景网格并生成区域标签；重叠区域按 App 的材料 1→2→3 优先级选择，环境区域丢弃。曲面采样只是用于构造离散边界，不是将体素当有限元单元。该路线尚未确保独立采样曲面之间的完全一致界面，固定包络只能相对**输入三角面**，不保证接近真实 TPMS。

仅在本机可信环境使用本地服务；不需要此后端时，其他已有浏览器功能照常使用。Linux / Python 3.11 示例：

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-wild.txt
npm install
TPMS_PYTHON="$PWD/.venv/bin/python" npm run serve
```

WildMeshing Toolkit 及 Python 包许可见其上游仓库；其他已有 Gmsh 等依赖仍受各自许可约束。服务端每次最多运行一个任务，提供取消、15 分钟超时、96³ 采样、150000 输入三角面和 500000 实体四面体上限，不能保证运行内存不会超过可用资源；不要将不受信任的服务暴露到公共网络。结果仍按材料、外边界、分量、非流形、网格质量和几何采样审查，实验结果一律禁止导出或求解。取消会终止后台进程；切换参数会丢弃过期结果。

现已添加便宜的前置过滤：比较各闭合材料曲面的体积与最多 96³ 的高密度中点材料采样，偏差超过 25% 时在昂贵体网格之前停止。24³ 二级/三级都因为材料 1 曲面体积 47394 mm³ 与 48³ 参考 174000 mm³ 不一致而拒绝；48³ 二级输入 305616 面超过安全上限，三级材料 2 曲面体积 387452 与 96³ 参考 559625 mm³ 偏差过大而拒绝。截图 `screenshots/simwild-preflight-{1,2}-{24,48}.png`。预检只排除明显错误，**通过不等于准确或拓扑正确**，也不能绕过面数限制。当前仍缺少保持交线、同时一致的多材料界面构造、对高频薄壁的高效自适应采样与验证；因此二级和三级任务未完成。

### 参考 TPMeSh：CGAL 直接隐式多材料网格（实验）

参考 TPMeSh 的直接隐式域、以壁厚选择尺寸、曲面近似容差、扰动和薄片消除思路，新增 CGAL Mesh_3 路线。与之前 SimWild 路线不同：CGAL 直接查询当前 App 的连续 `classify` 材料域，一次构建共享界面的多区域四面体；**不输入体素网格，也不先为每种材料独立构造曲面**。为避免每次求值调用 JS 解释器导致性能瓶颈，原生求值器逐项对应 App 的 `geo()`；GUI 自动测试覆盖 9792 个实际 App 参数点，逐材料场值误差 < 1e-11、材料编号一致。服务端同时核对 App 几何函数源指纹；源码不匹配时禁止运行，以免使用过期的原生几何。有限样本测试与源码指纹不是数学证明，须在变更几何后重新审查和更新测试。

**TPMeSh 本身不是多材料 App 网格器。** 它的近似定厚隐式式 `(S−t|∇S|/2)(S+t|∇S|/2)` 不等于本 App 的阈值几何，不能直接替换用户模型。它保护与外盒相交的特征线；当前 CGAL 试验尚未实现 App 的盒边、材料三重交线保护和薄壁特征种子，也没有证明所有材料或细壁都会被发现。TPMeSh 的删除小分量/极小单元清理策略也不能未经验证地用于这里，否则可能删除真实结构或材料。CGAL 面片/尺寸容差亦不自动保证真实 TPMS 的严格 Hausdorff 误差或每个壁厚方向有足够单元。

GUI 增加「估算壁厚并建议尺寸」：对无宿主的宏观双域二级/三级，用原隐式场的局部梯度计算材料壁厚一阶估计，给出 P10、中位数和 P10 ÷ 指定单元数的建议尺寸。它不保证识别最薄布尔交线，也不保证每处跨壁的实际单元数。默认二级预设 P10：材料 1 为 2.067 mm、材料 2 为 3.640 mm；三级：材料 1 为 2.067 mm、材料 2 为 1.669 mm、材料 3 为 4.006 mm。若目标 2 个单元，建议尺度分别约 1.034 和 0.834 mm。实际 GUI 截图 `screenshots/cgal-sizing-{1,2}.png`。因此之前试验的 8 mm 目标尺寸远大于估算薄壁，不能当成足够分辨率。

**实际网格状态：未达标。** 两个默认预设在 8 mm 尺度、0.2 mm 近似容差的 GUI 实验中，未设顶点上限的 CGAL 均产生超过 500000 个实体单元，未能送入浏览器审查；加入 100000 顶点中止后，二级和三级均在细化阶段达到限制，部分网格被丢弃。截图 `screenshots/cgal-implicit-{1,2}-gui.png`。这不是网格验证通过，也不意味着更细的壁厚目标可在当前资源内完成。CGAL 实验网格始终禁止导出或用于求解；下一步需要保护共享交线并改进特征捕获和局部尺寸策略，而不是简单加密。

可选 CGAL 后端须本地编译，源文件 `native/cgal-implicit.cpp` 使用 CGAL Mesh_3，**CGAL Mesh_3 和 TPMeSh 均受 GPL-3.0-or-later 约束**，分发时应遵守相应许可。需要 C++17 编译器、CGAL 6.x 头文件及 Boost ≥1.80 头文件；下面示例使用 CGAL v6.0.1 源码和 `boost-headers`，不会把大体积依赖或二进制提交到仓库：

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install boost-headers==1.85.0.post1
# 将 CGAL v6.0.1 源码解压到本地目录 CGAL_ROOT

export BOOST_INCLUDE="$PWD/.venv/lib/python3.11/site-packages/boost_headers/include"

```

可用 `TPMS_CGAL=/path/to/cgal-implicit npm run serve` 指定其他编译位置；SimWild 仍需单独的 Python 依赖。服务端限制同时一个原生任务、15 分钟超时、100000 顶点及 500000 实体单元；触发上限时丢弃未完成结果，但并不构成内存上限保证。不要将此本地开发服务暴露给不受信任的用户。测试：`npm test`、`npm run test:app-field-gui`、`npm run test:cgal-sizing-gui`、`npm run test:cgal-implicit-gui`；GUI 测试需要运行本地服务并设置 `CHROMIUM_PATH`。

默认二级和三级预设还通过 App GUI 检查了周期资格：均为 `2×2×2` 宏观周期；各方向共 2187 个平移点的材料标签一致，场值最大差约 `2×10⁻¹⁵`。开启梯度时被拒绝。截图 `screenshots/cgal-periodicity-{1,2}.png`。当前已实现周期单胞的隐式多材料划分和截面诊断，但尚未实现**单胞周期网格 + 严格协调拼接**；CGAL 周期单胞中的四面体可能跨外盒边界，不能简单复制后冒充完整有限域网格。

优化采用事务式复核：CGAL 扰动及 exude 前保存原网格；候选须无倒置/退化、最差 Jacobian 不降低、最大长高比不恶化、各材料体积变化 ≤2%，否则回滚。该门控不保证材料界面几何正确。另增加界面三角形重心两侧的材料标签抽样（偏移最多 0.25 mm），用于发现界面几何偏差；它也不是严格距离上界。简化参数（单胞尺寸 120 mm、`s=0.5`、`t₂=1.2`，目标尺度 20 mm、容差 2 mm）的 App 二级 GUI 链路测试中，CGAL 优化将最差 Jacobian 从 0.0028 提至约 0.0515，最大长高比从 300.74 降至约 12.52；但界面两侧标签只有 96/614 个采样匹配，曲面一阶距离估计 P95 37.726 mm，**仍严重不合格**。截图 `screenshots/cgal-custom-opt2-geometry.png`。这并非默认二级或三级验收。

GUI 的「划分周期单胞并诊断」现在通过 CGAL Periodic Mesh_3 直接划分当前 App 的单胞，提取真实四面体 Z=50% 截面，显示材料标签，并可执行 CGAL 周期 perturb/exude；优化候选须通过相同的质量和逐材料体积回滚条件。该路径目前仅支持无宿主、无梯度变换、整数周期、立方宏观单胞；它是周期域诊断，**不产生完整有限盒网格**。周期求解限制 270000 顶点（含临时虚拟副本）和单胞 500000 四面体。

实际 GUI 测试，目标 8 mm、包络 0.2 mm、优化每阶段限 2 秒：二级单胞约 179886 个四面体，最差 Jacobian 0.00014→0.02296、最大长高比约 37.47，约 8408 个单元跨单胞边界；三级约 443434 个四面体，最差 Jacobian 0.00048→0.02056、最大长高比约 35.88，约 23639 个跨界。按 8 个单胞估算约 144 万 / 355 万周期单元（不包含形成有限盒所需的裁剪工作）。结果随优化时限和机器调度有少量变化。两者仍远未达到质量阈值。GUI 截面见 `screenshots/cgal-periodic-cell-{1,2}-opt2.png`，完整指标见 `screenshots/cgal-periodic-mesh-{1,2}-opt2.png`。二级截面 256² 像素对照中仅 49128 个非混合像素有效（75.0%），其中 99.94% 材料标签相符；三级仅 31578 个有效像素（48.2%），其中 99.80% 相符。大量抗锯齿混合像素被排除，因此这**不是全截面一致率或三维误差保证**。

启动周期后端可用 `TPMS_CGAL_PERIODIC=/path/to/cgal-periodic npm run serve`；`CGAL_OPT=2 npm run test:cgal-periodic-gui` 验证两个真实 App 预设的诊断和截面截图。这一周期单胞网格尚未解决外盒截断、跨单胞共享节点、材料交线保护、三维几何误差及最终质量问题，不能作为完整结构网格或导出求解。

### 多级界面共节点与逐轮优化诊断

周期路径现在逐个检查相邻不同材料的公共三角面：三个顶点句柄须一致，且三个周期偏移之差须为同一平移；同时统计 1–2、1–3、2–3 界面，并最多抽取 2048 面，在法线两侧各 0.25 mm 对照 App 材料标签。`npm run test:shared-face` 测试节点重排、周期平移及不一致情况。这个检查只覆盖周期商网格的相邻材料公共面：**不保证边界几何精度、三重交线或有限盒裁剪拼接后的共节点。**

优化可运行 1–2 轮 perturb，随后可选择执行 exude；每阶段独立保存并复核，候选不得降低最差 Jacobian、增加最大长高比，且各材料体积相对优化前变化不超过 2%，否则回滚并停止进一步扰动。GUI 列出每阶段候选值及接受/回滚。针对真实二级单胞，四轮扰动后 exude 曾出现段错误；周期 ODT 候选后的扰动也曾崩溃，均未开放。即使限制为两轮，也不能保证 CGAL 在所有输入上稳定；原生进程异常时丢弃结果并报告信号。

重新编译当前源码后，真实 GUI（8 mm、0.2 mm、每阶段 2 秒、两轮）二级：179341 四面体，最差 Jacobian 0.00014→0.03228，最大长高比 27.46；28968 个 1–2 公共面，偏移对齐后 0 面不共节点；界面抽样 2044/2048 匹配。三级：443316 四面体，最差 Jacobian 0.00048→0.02056，最大长高比 33.95；90367 公共面（1–2 为 32114，1–3 为 0，2–3 为 58253），0 面不共节点；界面抽样 2039/2048 匹配。扰动两轮及 exude 均接受，结果因时限和调度可能变化。截面和指标截图分别为 `screenshots/cgal-shared-cell-{1,2}-opt2-cycles2.png`、`screenshots/cgal-shared-mesh-{1,2}-opt2-cycles2.png`。有效截面像素覆盖分别只有 75.0% 和 48.2%，因此其匹配率不代表整个截面或三维几何。

这两例仍未满足最差 Jacobian >0.3、长高比 <10 的质量门槛，且仍有大量跨单胞单元；**既不能导出，也不能用于求解**。有限盒共形拼接、特征交线保护和严格几何验证仍未实现。

### 质量不足的分布与较长优化试验

GUI 进一步将不达标四面体按邻面分为材料界面、自由边界和其余三类；同时邻接材料界面和自由边界者归入材料界面，三类互斥。判定仍是 Jacobian ≤0.3 **或**长高比 ≥10，不能用分类计数替代几何验证。真实二级两轮、每阶段 2 秒试验中分别为 30197/57809、18317/45610、35816/76024，总计 84330/179443（47.0%）不达标；三级分别为 81960/175862、27950/66249、94473/201047，总计 204383/443158（46.1%）不达标。两例界面分别有 28968 和 90365 个公共面，不共节点面为 0。质量不足遍及界面、自由边界和内部，并非仅有少量坏单元；数字随时间限制和调度变化。

同一 GUI 把每阶段时限加到 10 秒，两轮扰动后再 exude：二级最差 Jacobian 0.03228、最大长高比 20.39，仍远未达标；三级原生进程发生 SIGSEGV，未返回网格。该次试验没有证明延长时间可靠或足够，也不意味着已解决根本问题；不要将其用于求解。继续工作需要定位原生优化器崩溃和大量坏单元的成因，研究保持多材料界面的局部重网格及特征保护，而不是只增加时间或重复平滑。

### 更严格生成准则与质量分布回滚

周期单胞实验新增 CGAL 四面体「外接球半径 / 最短边」上限（1.4–2，默认仍为 2）。减小该值是**生成时**收紧准则，而非只在粗糙结果上重复平滑；它不能单独保证 Jacobian、壁厚或界面精度，且可能产生更多单元或达到资源上限。逐轮回滚条件也增加：相较上一接受阶段，质量不达标单元的**数量和比例均不得增加**；GUI 显示每阶段的不达标数量、比例及接受/回滚。测试 `npm run test:periodic-quality-gate` 验证两项约束。

真实二级 GUI、8 mm / 0.2 mm、上限 1.4、两轮各 2 秒：240268 四面体，最差 Jacobian **0.05878**、最大长高比 **15.80**，不达标 59614/240268（24.8%）；31650 个材料公共面、0 个周期偏移对齐后不共节点面，界面两侧 2047/2048 抽样匹配。相同设置下上限 2 的一次对照为 179482 四面体、Jacobian 0.03228、长高比 27.13、不达标 84382/179482（47.0%）。优化受时限和调度影响，这只是一次实验对照；界面标签抽样与截面有效像素均非几何精度证明。截图 `screenshots/cgal-shared-{cell,mesh}-1-opt2-cycles2-ratio1.4.png`。

实际三级使用 1.4 时，单胞四面体超过 500000 上限而被丢弃，GUI 测试 `npm run test:cgal-periodic-limit-gui` 确认没有暴露部分网格。**二级质量虽有改善仍不达标，三级严格准则尚未生成成功；有限盒拼接仍未实现，均不可导出或求解。**

### 三级单胞的进一步质量与稳定性试验

发现先前的阶段门控有一个实际缺陷：当最差 Jacobian 与最大长高比不变，但整体不达标单元数和比例均下降时，仍会回滚。现在允许这类**质量分布严格改善**的候选，前提仍是两个极值不恶化、各材料体积满足原有约束，不达标数量和比例均不增加；只要数量或比例之一严格下降即可构成分布进展。测试包括无改善、占比恶化和数量增加等边界情况。

对真实三级单胞，半径边长比 1.7 仍超过 500000 单元；1.9 的一次命令行测试中，完成两轮扰动后进入 exude 时发生 SIGSEGV。GUI 新增可关闭 exude 的实验选项（默认仍开启）；**关闭它不保证其他阶段稳定，也不是崩溃修复**。真实 GUI 用 1.9、每轮 2 秒、两轮扰动、关闭 exude：第二轮极值不变，但不达标单元由 209782/461551 降至 209045/460927，因此被新门控接受；最终 Jacobian 0.01158、最大长高比 49.08，91043 个材料公共面、0 个周期偏移对齐后不共节点面，两侧标签 2038/2048 抽样匹配。截图 `screenshots/cgal-shared-{cell,mesh}-2-opt2-cycles2-ratio1.9-exude0.png`。该结果仍严重不合格，也不一定优于开启 exude 的其他试验；只能用于诊断，不能导出或求解。

### 验收指标导向扰动（实验）

CGAL 默认扰动按最小二面角排序，并非直接优化本项目的 Jacobian 和长高比。现增加可选的自定义扰动指标：每个四面体评分 `min(最小角点 Jacobian / 0.3, 10 / 最大长高比)`，只有评分严格大于 1 才同时满足两项质量阈值。该指标用于 CGAL 周期扰动的局部候选排序，禁用 CGAL 单元评分缓存以免混用不同指标；每阶段仍按全局最差质量、不达标数量与比例、材料体积复核和回滚。这不是几何误差证明，也不保证全局最优。`npm run test:tet-quality-score` 覆盖正四面体、缩放平移、薄片、退化及倒置。

为避免未经验证的优化组合，选择该实验指标时必须关闭周期 exude；GUI、服务端和原生程序均拒绝两者同时启用。该禁令不意味着扰动没有崩溃风险。真实 App、8 mm / 0.2 mm、两轮各 2 秒、关闭 exude 的对照：

- 二级、半径边长比 1.4：普通二面角扰动的一次命令行结果 Jacobian 0.03505、长高比 22.69；直接指标 GUI 结果 0.07510、13.97，64726/244584 个单元仍不达标，31648 个材料公共面中 0 面不共节点。
- 三级、半径边长比 1.9：普通扰动的一次 GUI 结果 Jacobian 0.01158、长高比 49.08；直接指标 GUI 结果 0.03107、31.35，209326/461161 个单元仍不达标，91037 个材料公共面中 0 面不共节点。界面两侧 2041/2048 样本匹配，非严格界面精度保证。

结果依赖时限和调度，上述仅为实验对照，不保证不同运行的质量分布都改善。真实截面截图 `screenshots/cgal-shared-cell-1-opt2-cycles2-ratio1.4-exude0-direct1.png`、`screenshots/cgal-shared-cell-2-opt2-cycles2-ratio1.9-exude0-direct1.png`。二、三级仍未满足 Jacobian >0.3、长高比 <10，完整有限盒网格与共形拼接也未完成；禁止导出和求解。

### 周期单胞质量截面与更深入的扰动试验

周期网格截面新增质量模式：红色表示该截面所属四面体的角点最小 Jacobian ≤0.3 或最大长高比 ≥10，绿色表示这两项均通过。截线仍是实际四面体截线；它只展示单胞 Z=50% 平面，不是三维全部质量的统计。材料模式的独立像素对照不受颜色切换影响；更改结构会清除截面缓存，防止重画过期结果。实际二级和三级质量截面分别见 `screenshots/cgal-quality-1-opt10-ratio1.4-direct1.png` 和 `screenshots/cgal-quality-2-opt2-ratio1.9-direct1.png`。

真实二级（8 mm、0.2 mm、半径边长比 1.4、直接质量指标、禁用 exude、每轮最多 10 秒）的 GUI 试验：244002 个四面体，最差 Jacobian 0.08536，最大长高比 11.63，仍有 64082/244002（26.3%）不达标；31648 材料公共面，周期偏移对齐后不共节点为 0。两侧标签 2044/2048 抽样匹配，不能证明三维界面精度。优化仍远未达标，增加时限也没有解决大量坏单元。

另外通过临时编译测试 CGAL 直接指标的扰动步长：从默认 0.05 调大到 1.0（试图直接处理所有不达标单元）时，二级候选不达标数从 67072 增至 67109，质量门控正确回滚；0.2 的一次结果为 Jacobian 0.06010、长高比 16.95，未优于既有 0.05 对照。这些步长并未开放为产品选项。仍需研究能同时保持真实界面与共节点的局部拓扑重构、特征保护和可靠的有限盒拼接；当前禁止导出及求解。

### 生成阶段失败类型与直接细化探针

**根本问题仍在生成路径，而非截面绘图。** 现在按“仅 Jacobian 不达标 / 仅长高比不达标 / 两者均不达标”分别显示生成后、优化后的全单胞四面体数。真实二级（比值 1.4、直接扰动、各阶段 10 秒）生成后为 63974 / 0 / 3098，优化后为 63712 / 0 / 368；三级（比值 1.9、直接扰动、各阶段 2 秒）生成后为 202328 / 0 / 9140，优化后为 202157 / 0 / 7278。这表明优化主要减少极端细长单元，仍留下大量 Jacobian 不达标单元；分类不等于已经定位具体几何根因，也不能证明每个不良单元都是薄片。运行时限和调度会影响数值。真实 GUI 指标截图 `screenshots/cgal-failure-types-{1,2}.png`。

隔离试验在 CGAL Delaunay **生成时**直接把 `min(Jacobian/0.3, 10/长高比) ≤ 1` 的单元设为细化对象，而不先生成粗网格后平滑。真实二级、8 mm / 0.2 mm、半径边长比 2、未优化、100000 顶点上限（含周期虚拟副本）下：普通准则完成并得到 39529 节点 / 184692 四面体；直接质量细化达到 100000 顶点上限，未完成、结果丢弃。这说明在这一输入和资源限制下，简单把验收指标塞进现有圆心细化不能解决问题；不能据此断言该方法对所有输入不终止。探针通过 `-DTPMS_QUALITY_REFINEMENT_PROBE` 编译，固定更低顶点上限，不接入 GUI、默认构建或求解流程；`native/experimental-refinement-criterion.hpp` 保留实验以便复核，禁止视为可用网格器。

当前的多材料隐式网格仍缺少对薄壁、材料交线及周期有限盒拼接的特征保护；质量、真实界面几何与完整盒共节点均未通过验收，禁止导出或求解。

### 多材料边界拓扑检查与回滚保护

之前的“公共面共节点不匹配为 0”**不能说明材料边界本身是流形的**。现在按周期偏移归一化边，分别统计各材料边界三角面的边邻接数：封闭材料边界的每条边必须有 2 个邻接三角面，1 个是单面边，超过 2 个是多面边。各材料独立计数，正常多材料交线不会因不同材料的面数相加被误报。该检查只是必要条件，未验证顶点邻域、连通性或几何正确性，也不能代替有限盒拼接检查。`npm run test:periodic-edge-audit` 覆盖周期平移、反向边、共享面的两个闭合四面体及异常邻接。

质量优化每阶段新增拓扑门控：相对上一接受阶段，各材料的单面边、多面边数量均不得增加，否则回滚；这只限制分类总数，不证明异常边的位置未改变或界面几何被严格保持。真实二级（1.4、直接扰动）材料 2 有 9 个多面边；真实三级（1.9、直接扰动）生成后材料 2 / 3 分别有 59 / 55 个多面边。一次三级候选虽然 Jacobian 0.00048→0.03000，但材料 3 多面边 55→57，故被回滚，最终保留未经改善的初始网格。多面边可能反映离散网格或原始隐式几何的接触/交线问题，尚未确定成因。GUI 截图 `screenshots/cgal-edge-gate-{1,2}.png`。这些结果推翻了仅凭“共节点 0 不匹配”就认为多材料边界合格的任何推断，仍禁止导出或求解。

补充隔离试验：在直接质量细化探针中增加 2 mm **单胞外接球半径下限**，使小单元不再继续按质量细化。真实二级完成于 192078 四面体，但 78734（41.0%）仍不达标，最差 Jacobian 0.00038，材料 2 仍有 7 个多面边。这个下限可能压制薄壁所需的细化，不满足几何验收要求，因此只作为对照，**不接入 GUI 或默认生成流程**；通过同时定义 `TPMS_QUALITY_REFINEMENT_PROBE` 和 `TPMS_QUALITY_REFINEMENT_MIN_SIZE` 才能编译试验版本。

### 多面边附近的原始材料场采样

新增对多面边的多尺度诊断：沿每条边中点的正交圆环，在半径 0.05、0.1、0.25 mm 各取 48 点，通过原始 App 分类器计算该材料在圆环上的 0、1 或多个相连扇区；最多检查 2048 个“边–材料”样本。圆环会按周期包裹，测试 `npm run test:ring-sectors` 覆盖循环首尾合并、全有/全无、多扇区及合成场。GUI 截图 `screenshots/cgal-rings-{1,2}.png`。

真实二级材料 2 的 9 条多面边：半径 0.05 mm 为 6 / 3 / 0（无 / 单 / 多扇区），0.1 mm 为 4 / 5 / 0，0.25 mm 为 1 / 3 / 5。真实三级在回滚后的 59 条材料 2 多面边：三个尺度分别为 49 / 10 / 0、38 / 21 / 0、2 / 21 / 36；55 条材料 3 多面边分别为 1 / 54 / 0、1 / 54 / 0、0 / 21 / 34。数值仅为该次运行的离散采样；跨尺度变化说明不能用单一尺度的结果判定根因。尤其 0.05 mm 小于网格曲面近似容差 0.2 mm，圆环未出现对应材料既可能是离散界面偏移，也可能是几何局部形态或采样不足，不能据此断言哪一原因，更不能证明实际几何为流形或非流形。

该诊断并未修复多面边、薄壁或四面体质量，亦未完成有限盒共节点拼接。优化仍在材料边界异常增多时回滚；结果继续禁止导出和求解。
